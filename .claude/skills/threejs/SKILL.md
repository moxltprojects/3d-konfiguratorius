# Three.js Expert

When working on Three.js code:

1. Check the installed Three.js version first.
2. Before implementing a non-trivial feature, search the official
   Three.js examples in ~/threejs-reference/examples/.
3. Prefer official examples as implementation references.
4. Reuse established Three.js patterns for:
   - loaders
   - controls
   - post-processing
   - shaders
   - animation
   - WebGPU
   - instancing
   - environment maps
   - particles
   - physics integrations
5. Adapt examples to the project's architecture.
6. Never blindly copy an example if its API is outdated.
7. Prefer the current official API and patterns.
